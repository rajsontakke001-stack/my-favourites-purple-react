git commit -m "Initial commit - Light On Off React"# My Favourites — React + Vite

A simple favourites project with a purple/lavender and pink colour theme, gentle transitions, and profile photo loading from Wikipedia.

## Run

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Features
- Actor, Actress and Cricketer dropdowns
- More personalities in each category
- Updates the photo and details when a person is selected
- Tries to fetch the latest available Wikipedia page image
- Subtle entrance and photo fade animation
- Responsive layout

Photos require an internet connection. Wikipedia page images can vary and may not always be the newest photo. A placeholder appears if no photo is available.
